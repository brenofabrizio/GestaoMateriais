# Serviço de IA

Este serviço será criado quando os fluxos transacionais estiverem estáveis.

Tecnologia planejada:

- Python;
- FastAPI;
- Pydantic;
- Celery ou worker dedicado;
- Integração com modelos via provider configurável;
- Controle de acesso herdado do backend Django.

A IA não poderá alterar estoque, aprovar compras ou concluir entregas sem uma ação humana autorizada.
